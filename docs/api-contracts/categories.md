# Categories API (existing)

Base prefix: `/api/v1/categories`

- `POST /api/v1/categories` — create (201)
- `GET /api/v1/categories` — list
- `GET /api/v1/categories/{category_id}` — retrieve
- `PATCH /api/v1/categories/{category_id}` — update
- `DELETE /api/v1/categories/{category_id}` — delete (204)

Category-attribute association routes are documented in attributes-and-variants.md.
