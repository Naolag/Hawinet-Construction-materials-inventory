# Measurement Units API (existing)

Base prefix: `/api/v1/measurement-units`

- `POST /api/v1/measurement-units` — create (201)
- `GET /api/v1/measurement-units` — list
- `GET /api/v1/measurement-units/{unit_id}` — retrieve
- `PATCH /api/v1/measurement-units/{unit_id}` — update
- `DELETE /api/v1/measurement-units/{unit_id}` — delete (204)

There is not currently an item-specific unit-conversion API in the inspected router.
