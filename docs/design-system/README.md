# Hawinet Design System

## Core 2+1 palette
- Soft Alabaster — `#F8FAFC`: page canvas and whitespace.
- Deep Charcoal — `#1E293B`: typography, navigation structure and primary contrast.
- Muted Cobalt — `#2563EB`: primary actions, selected states and key highlights.

Supporting neutrals: `#E2E8F0` borders and `#64748B` secondary text. The left navigation remains dark charcoal on desktop, tablet and mobile.

## Layout principles
- Persistent dark sidebar on desktop and tablet.
- Mobile navigation drawer closes after a destination is selected.
- Light page canvas with white bordered panels.
- Compact, information-dense tables on larger screens.
- Stacked cards and forms on mobile.
- Use a restrained accent; don't make every status a different color.

## Typography and components
Inter is the primary interface font. Use consistent page headers, metric cards, panel headers, form fields, status labels, toolbars, tables, pagination, confirmation dialogs and responsive navigation.
