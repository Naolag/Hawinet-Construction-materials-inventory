# Hawinet Design System

## Core 2+1 palette

- Soft Alabaster — `#F8FAFC`: canvas and page background.
- Deep Charcoal — `#1E293B`: typography, structure and dark navigation.
- Muted Cobalt — `#2563EB`: primary actions, active states and highlights.

The original dark sidebar is retained as a distinct navigation surface. Content surfaces use white cards, subtle `#E2E8F0` borders and muted `#64748B` secondary text.

## Responsive principles

- Desktop: fixed dark sidebar, dense tables and multi-column content.
- Tablet: compact navigation and adaptive metric grids.
- Mobile: off-canvas navigation drawer, stacked page headers, compact cards and horizontally scrollable data tables.
