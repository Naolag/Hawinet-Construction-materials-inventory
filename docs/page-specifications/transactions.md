# Transactions

Direct port of Framer TransactionsWorkspace. One New Transaction selector with six types: Stock Receipt, Sale, Customer Return, Supplier Return, Stock Increase and Stock Decrease. Includes history filters/tabs, draft and posted detail states, item rows, payments, payment history, add-payment dialog, draft editing and void confirmation. Transaction date and ID are generated automatically. Sales support Paid, Partially Paid and Unpaid. Returns select an original posted transaction. All behavior is local prototype state only.
