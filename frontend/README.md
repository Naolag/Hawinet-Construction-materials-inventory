# Hawinet Frontend

Design-only Next.js implementation of the Hawinet construction-material inventory UI.

## Run locally

```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:3000.

## Scope

- Recreates the Framer workspace layouts for dashboard, products, inventory, transactions, reports, measurement units, unit conversions, categories, employee management and settings.
- Uses illustrative, local sample data only.
- No backend/API/database integration, authentication, or real transaction processing is included.
- Forms are visual prototypes; save/post actions are not connected to business logic.

The design reference is the Hawinet Framer project. Visual comparison should be performed at matching desktop, tablet and mobile viewport sizes before claiming pixel-level parity.
